∿ AFS

Sync anything to audio.

Spec / Source

An open file format that fingerprints audio into a stream of time cues. Any device hearing the source (via microphone or local audio) matches the fingerprints to locate itself and stay in sync in real time.

› status / idle

Use your own files

Drop in any media file with a matching SRT to test AFS on your own content. If you don't have an AFS file, one will be generated in your browser.

Audio decoding happens in your browser. Files never leave your device. Generated AFS files can be downloaded once ready.

Try it

Listen · Microphone

Open this on another device. It listens via the microphone and stays in sync with whatever audio it hears — no network connection needed.
